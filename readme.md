# AI Agent에게 일 제대로 시키는 법 배우기 — 미션 산출물

매주 1개의 모바일 웹 미니게임을 기획·제작하는 과정에서 발생하는 기획 피로도와 아이디어 고갈 문제를 해결하기 위해, **게임 기획 보강 AI 에이전트(아케이드 닥터)**를 설계·비교·검증한 미션 기록입니다.

* **선정 과업:** 모바일 미니게임 기본 컨셉·시나리오 기반 전개 방향, 핵심 재미 요소, 몰입도 증강 기믹 기획 보강
* **실전 테스트 소재:** `FPV Hunter` (3D FPV 드론 폭격 아케이드 게임)

---

## 산출물 문서 목록 (읽는 순서)

1. **[LLM 모델 비교와 선정 보고서](./docs/model-comparison.md)** — 동일한 `FPV Hunter` 기획 보강 프롬프트를 3종 이상의 LLM 모델에 입력하고, 4개 기준으로 채점해 최종 모델을 선정한 보고서입니다.
2. **[시스템 설계 문서](./docs/system-design.md)** — 페르소나 6요소, 시스템 프롬프트(v1/v2), Few-shot 예시 3건, 재사용 입력 템플릿, 환각 검증 전략 및 Pass/Fail 판정, 카테고리 분류를 담은 설계 기록입니다.
3. **[실행 로그](./docs/run-log.md)** — 선정한 모델과 10턴 이상 수행한 무편집 대화 원문(조건 변경, 동일 입력 반복, 환각·문맥 끊김 표시 포함)과 항목별 작업 기록입니다.
4. **[미해결 기록](./docs/unresolved.md)** — 프롬프트를 반복 개선해도 끝내 원하는 결과를 얻지 못한 과업 2건과 시도한 프롬프트, 직접 작성한 막힌 이유를 기록한 문서입니다.
